# ☁️ (aka. fog)

a nix expression suspend a visitable aerosol consisting of tiny services or
artifacts on computers. the term _fog_ is typically distinguished from the more
generic term _cloud_ in that fog is low-lying, and the kind of data in the fog
is often generated locally (such as from friends, like [OccultOS])

# formation

fog condenses hosts, such as `/lemma` and keys found in `/users/keys.json` into
a evaporation.
